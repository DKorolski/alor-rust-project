# alor-types

`alor-types` содержит общие доменные типы контрактного уровня для интеграции между `alor-gateway`, рантаймами и стратегиями.

Вынесенные типы:

- `PositionSnapshot`
- `PositionsSnapshot`
- `OrderSnapshot`
- `OrdersSnapshot`
- `StrategyBar`
- `StrategyContext`
- `Action`
- `Side`
- `StrategyCore`

`alor-gateway` больше не зависит от `alor-scalping` для этих типов.
